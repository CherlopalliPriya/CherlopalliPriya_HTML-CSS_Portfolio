CHERLOPALLI PRIYA - PERSONAL PORTFOLIO
=====================================

PROJECT OVERVIEW
----------------
This project is a responsive personal portfolio website created using HTML5 and CSS3. It introduces Cherlopalli Priya, a third-year B.Tech Computer Science and Engineering student at VEMU Institute of Technology. The website presents her profile, education, skills, projects, and contact information.

OBJECTIVES
----------
- Create a personal portfolio to present academic and technical details.
- Showcase skills and project work in a clear, organised layout.
- Practise semantic HTML and CSS styling.
- Make the website usable on desktop, tablet, and mobile screens.

TECHNOLOGIES USED
-----------------
- HTML5
- CSS3
- Flexbox and CSS Grid
- Responsive CSS media queries

PROJECT CONTENT
---------------
- Home: Introduction and welcome section.
- About: Personal and educational overview.
- Skills: Technical skills.
- Projects: Includes Learn Mate and Student Attendance Management System.
- Contact: Contact information and a demonstration contact form.

FILES AND FOLDERS
-----------------
- index.html: Main webpage content and structure.
- style.css: Website design, layout, colours, and responsive styling.
- favicon.svg: Website icon displayed in the browser tab.
- Cherlopalli-Priya-Resume.pdf: Resume linked from the portfolio.
- project-description.txt: Additional project description.
- screenshots/desktop.jpg: Desktop layout preview.
- screenshots/mobile.jpg: Mobile layout preview.

HOW TO RUN THE WEBSITE
----------------------
1. Download the portfolio ZIP file.
2. Extract all files into a folder.
3. Open the extracted folder.
4. Double-click index.html to open the website in a web browser such as Google Chrome.
5. To edit the website, open the folder in Visual Studio Code and modify index.html or style.css.

No installation or server is required to view the basic website locally.

IMPORTANT NOTE
--------------
The contact form is a visual demonstration only. It does not send or store messages because no backend or form service is connected.
